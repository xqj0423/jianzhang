# 快捷指令生成器

生成器通过环境变量 `SHORTCUT_API_ORIGIN` 读取目标 HTTPS 网站地址。生成文件写入 `generated/`，不进入 Git；不得把个人网站的已安装工作流或连接配置上传。

运行 Python 3 的 `build.py` 后得到未签名 plist 工作流。签名与安装需要另外完成，公开源码不附带个人证书、签名文件或 token。安装时的个人配置输入框保持为空，由使用者在自己的 iPhone 粘贴网站提供的连接配置。

生成器不会从环境变量或文件读出并写入 `SHORTCUT_WRITE_TOKEN`。后端仍通过这个环境变量验证手机请求，但其值只应放在服务端配置及用户自己的手机上。
