- `api/index.mjs`：不再打包签名工作流；下载由配置的后端转发。
- `backend/src/database.ts`：显式读取 CloudBase 环境、可选凭据和集合/文档配置，没有数据库真实连接值。
- `backend/src/book-access.ts`：密码、会话密钥、快捷指令令牌继续从环境变量读取；访问模式也由环境变量控制。
- `backend/src/server.ts`：个人工作流从 `SHORTCUT_FILE_PATH` 读取，不要求把文件放入 Git。
- `shortcut/build.py`：个人地址改读 `SHORTCUT_API_ORIGIN`，生成文件不提交；配置导入问题默认值保持空。
- `backend/build.mjs`：替代会复制私密 `.env.local` 的旧 prepare/deploy 脚本。公开版不提供带真实 envVariables 的云配置。

多用户分支需要关闭 Vercel 与后端的 BOOK_PUBLIC_ACCESS，并配置 OWNER_EMAIL、RESEND_API_KEY、MAIL_FROM；尚未部署，不会改变正在使用的网站。发布前保留原 BOOK_SESSION_KEY、数据库和旧快捷指令令牌，不能直接覆盖上线。
